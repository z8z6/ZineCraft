# 泰拉十九国城市与重要地区目录

## 口径

- 国家、城市和地区名称以 [PRTS 泰拉大典：地理](https://prts.wiki/w/泰拉大典:地理) 当前目录为准，整理日期为 2026-08-20。
- 本页只整理 PRTS 已明确列出的国家归属和地名层级，不补写城市坐标、国界形状或未公开的上下级关系。
- “城市与聚落”包含移动城市、城市、城镇、村落及明确的城市辖区；“重要地区”包含行政区、河湖山地、荒原、矿区、道路等。
- 少数地名的类型在现有资料中并不明确，保留在“其他已知地名”，避免凭名称自行推断。
- 国家边界属于固定地图数据；城市是国家内的地点数据；群系是气候与地貌数据，三者不能互相替代。

## 游戏数据边界

当前实现将十九个国家作为固定地图区域，并把本页的顶层城市、聚落和重要地区制作成 JourneyMap
地点覆盖层。由于资料没有为全部地点提供统一精确坐标，坐标和边界明确属于游戏化布局，不声称是真实位置，也不直接控制建筑自然生成。

布局原则、十九国数量和图层行为见[泰拉城市与地区游戏化布局](TERRA_PLACE_LAYOUT.md)。后续若获得更高可信地图资料，可以在保留地点稳定
ID 的前提下修订坐标；不能借用群系边界充当城市边界。
