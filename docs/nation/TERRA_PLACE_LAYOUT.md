# 泰拉城市与地区游戏化布局

状态：`ORIGINAL GAMEPLAY LAYOUT`  
地名与国家归属：`CANON/B（PRTS 对游戏资料的整理）`  
坐标、半径与边界：`ORIGINAL（非官方地图坐标）`

## 设计边界

PRTS 能确认城市、聚落、行政区和自然地区的名称及国家归属，但目前没有为全部地点提供可直接换算为 Minecraft
坐标的统一精确地图。因此本项目不声称还原官方城市位置，而是在已经确定的十九国边界内提供稳定、可审计的旅行地图布局。

地点数据位于 `TerraGeography`，类型与坐标契约位于 `TerraPlace`。全部 187 个地点使用 PRTS 中文名；没有核实到官方英文名的条目在
`en_us` 暂时保留原名，避免自行创造译名。

## 分布规则

- 每国目录中的第一座主要城市、聚落或城区位于国家锚点，作为地图阅读中心，不表示官方首都判断。
- 其余城市、聚落和城区沿国家内圈的稳定黄金角螺旋分布，距离锚点约 `1050—2850` 格。
- 行政区、矿区、荒原、河湖和山脉位于 `2250` 格外圈；条目多于 7 个时增加 `3150` 格第二外圈。
- 每国使用独立起始角度，避免所有城市沿同一方向排列。顺序和角度由代码固定，不使用世界种子或运行时随机数。
- 城市边界为半径 `420` 格的近圆形；聚落为 `280` 格。
- 城区和行政地区统一使用 `REGION` 类型，为 `820 × 615` 格椭圆；自然地貌为 `1050 × 787` 格椭圆。
- 地点中心初始化时必须属于声明国家；JourneyMap 绘制边界时再裁剪到国家 Voronoi 多边形，任何城市或地区都不能跨越国界。
- 地图边界只表达旅行导航范围，不等于行政法理边界、移动城市实际尺寸或建筑自然生成范围。

## JourneyMap 图层

- `泰拉国家边界`：19 个国家的大范围边界与国家名。
- `泰拉城市与聚落`：城市、城镇和村落，使用较高填充透明度及较大文字。
- `泰拉重要地区`：城区、行政区、矿区、道路、河湖、山脉和荒原，使用较低填充透明度。

三个图层可以在 JourneyMap 中分别开关。所有覆盖层只绑定 `zinecraft:terra`，不会显示在主世界。
