# Zinecraft 开发路线

本文档记录当前路线，不再讨论多 Loader 选型。项目固定面向 Minecraft 1.21.1、NeoForge 21.1.244 和 Java 21；除非另立迁移项目，不维护
Fabric/Forge/Quilt 兼容层。

## 已建立的基础

- 单模块 Java 项目与按领域拆分的声明式目录。
- 泰拉独立维度、十九国群系、国家地表材料、聚落和唯一地标。
- 星门传送、拉特兰中心与固定原点结构。
- Curios 藏品栏、集成战略藏品资料和服务端效果。
- 技能物品与 Ponder 演示。
- 服务端权威 Weapon Runtime 与 TaCZ 外置枪包格式适配。
- FTB Quests 远征、国家档案、关系网和开发说明。
- `test`、`runData`、`build`、`runClient` 开发验证链路。

## 近期优先级

1. 继续把迁移后仍偏机械的 Java helper、参数名和集合循环改为可维护的领域 API。
2. 完善十九国原创 16×16 纹理、建筑模板、居民皮肤和特色生态，不以原版占位内容作为最终方案。
3. 为星门、拉特兰中心、天灾区和源石晶簇群补充游戏内回归测试。
4. 扩展藏品服务端效果并维护 PRTS 来源、原文和权利记录。
5. 增加服务端 Mob 武器 AI、武器状态同步测试和更完整的动作取消规则。
6. 在不授予客户端玩法权限的前提下，重新设计可维护的 TaCZ 动画子系统。
7. 清理示例物品、示例配方和占位资源，形成可发布内容基线。

## 长期方向

- 国家探索、外交、贸易与声望的存档化玩法。
- 泰拉生产线、材料链、食品和特色装备。
- 更完整的敌对生物、国家居民行为和特殊事件。
- 任务叙事、教程、配置界面与无障碍本地化。
- 大型世界的生成性能、客户端表现和专用服务端稳定性。

## 开发规范

- Java 21，2 空格缩进；公开 API 使用 Javadoc，特殊玩法规则使用中文注释解释原因。
- 资源 ID 为 `zinecraft:<snake_case>`，注册名、翻译、贴图、声音和数据路径保持一致。
- 通用端与客户端职责分离；伤害、弹药、技能和任务状态由服务端决定。
- 新内容优先使用领域目录和数据生成器，不创建无必要的 Loader 或注册表抽象层。
- 明日方舟资料只引用官网和 PRTS 已有内容，不自行推断；外部素材逐文件记录来源和权利说明。
- 完成内容变更前运行 `test`、`runData` 和 `build`，运行时风险较高时再验证 `runClient`/`runServer`。
