# 泰拉国家材质

十九国各拥有一套“地貌 + 建筑主体外墙”材质。地貌材质及未列入 CG 清单的专用材质以 PRTS 国家地理、代表城市和关卡材料分区为语义依据，由项目确定性脚本生成原创
16×16 像素纹理。十九张建筑主体外墙则按用户指定，直接从本地保存的《明日方舟》官方背景画面以固定坐标 1:1 裁为 128×128 RGB
PNG；它们是官方画面的裁切衍生物，既不是原创像素纹理，也不代表无缝官方材质。两类资源的来源与权利声明必须分开。

## 资源与权利说明

- 十九张建筑主体材质现由 `script/generate_nation_cg_wall_textures.ps1` 从用户指定的游戏背景图以固定坐标 1:1 裁切为
  128×128；其中十八张覆盖既有外墙 ID，并新增已注册的 `sami_tribal_timber`。它们是官方画面的裁切衍生物，**不是本项目原创像素纹理
  **。
- `sami_ritual_stone` 未被木构画面覆盖，仍保留原有原创纹理；地貌材质和其他未列入裁切清单的专用材质仍由原确定性脚本生成。不同来源类别不能统一声称为原创或统一授权。
- 每张裁片的源文件、坐标、场景限制和发布风险见 [CG_MATERIAL_SOURCES.md](CG_MATERIAL_SOURCES.md)
  。原始画面与裁片权利归《明日方舟》相关权利方所有，本项目的来源记录不构成再分发授权。
- 裁片不包含角色、文字、徽标或明显 UI，但公开发布 JAR/资源包前仍需确认官方同人内容规则与所需许可。
- 物理属性复用原版方块模板只影响硬度、声音等交互参数，不复用原版贴图或模型视觉。
