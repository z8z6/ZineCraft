# 泰拉国家特色食物

本模组为十九个泰拉国家各注册一种可合成、可食用的代表食品。选题优先采用
PRTS“生息演算”行囊中已经带有国家指向的食品；资料未覆盖的国家，再从《明日方舟：终末地》的料理概念中选择相近原型并进行项目内转译。

> “直接参考”表示沿用 PRTS 条目名称或其明确的国家描述，不等于该食物被官方设定为该国唯一国菜。“项目改编”是 Zinecraft
> 为补齐十九国内容所做的原创适配，不应当作官方设定引用。

## 材质规范

- 文件为透明背景的原生 16×16 PNG，位于 `assets/zinecraft/textures/item/`。
- 每个食品使用所属国家既有配色与器物语言，但轮廓必须能在物品栏尺寸下辨认。
- 材质均为项目原创像素图，不复制 PRTS、明日方舟或终末地的游戏图标。
- `script/generate_nation_food_textures.ps1` 是可重复执行的确定性源脚本；AI 生成图只用作色块、轮廓和可读性的美术方向样张，不作为发布资产。
