## 共通章节

- PDF 50：移动城市以源石为燃料；地块群启动伴随汽笛、底部动力和烟尘，核心价值是躲避天灾、保全人口与财产。
- PDF 51：并非所有人都居住在移动城市，固定村镇和古老迁徙生活仍大量存在。不能把每套聚落都移动城化。
- PDF 52：移动城通常沿可通行航道周期移动，难以跨越山地和大河；核心地块指挥塔兼中枢控制、源石浓度与天灾监测。国别变体包括伊比利亚底部水栖装置、尚蜀地块堆叠山丘并架设索道。
- PDF 53：多数移动城分上/中/下三层，即生活层、支持层、动力层；人员物资通过地块边缘升降电梯流动。核心地块上部为指挥塔、下部为主源石动力炉；支持层用液压挂钩和锚定管线实现地块硬驳接。
- PDF 54：动力层底部最常见巨型履带；地块边缘有通用连接区，部分城市建造人工自然景观。
- PDF 55：生活层包含道路、桥、公园和绿地；地块缝隙常用牵引桥。地下有电缆/水管隧道，寒地增加暖气管，并有地下室和紧急避难空间；长期改扩建会形成黏合建筑和迷宫式地下空间。
- PDF 56：支持层类似巨大生产车间，含源石锅炉、供电、水循环和贯穿生活层的管线；新地块可承担紧急疏散，旧地块往往只是电梯/港口运输中枢。
- PDF 57：动力层包含履带传动、源石动力炉和源石储运；每块地块都有巨型动力炉，移动时禁止居住。维多利亚等工业国会用多块特殊地块组成巨型“工业坞”直接生产新地块。
- PDF 58：相当比例的中小移动城由采矿平台等移动设施持续改扩建而来。
- **通用设计约束**：国家差异应主要落在生活层轮廓、支持层功能和特殊机动结构；三层结构、地块连接、能源/水/物流系统是移动城市设计的硬约束。
- 国家章目录从书内 107 页开始，PDF 实际页约多 8—9 页。

## 维多利亚

- PDF 121：地貌从东北高原台地，经中央谷地，过渡到西南丘陵平原。
- PDF 123：郡下移动城市称“市”，固定聚落称“村/镇”；完整移动城市可单独设郡。伦蒂尼姆单一地块已超过一般中小移动城，地块按工业、农业等功能分工，并设城墙。
- PDF 125：机械工程和移动城市技术领先。
- PDF 126：半数以上人口居住在移动城市。
- **设计约束**：伦蒂尼姆必须先表达巨型多地块、产业分区、城墙和机械工程，不能从红砖小镇或蒸汽装饰开始。

## 莱塔尼亚

- PDF 136：政府机关多以“高塔”存在，高塔是权力象征；繁华移动城高楼林立并有贵族高塔。
- PDF 138—139：山脉、河谷、平原和温带茂林；早期城镇及移动城市发源于山间河谷/平原。
- PDF 140：无固定首都。
- PDF 145：有千万人居住在移动城市。
- **设计约束**：以塔群、移动城和音乐/源石技艺组织城市，不得只做普通历史砖镇或紫色魔法砖。

## 乌萨斯

- PDF 151：国土西低东高，平原—丘陵—山脉呈阶梯分布。
- PDF 153：省辖固定聚落与移动城市。
- PDF 155：主要城市是工厂林立的工业基地；圣骏堡周边移动城市群为工业核心，宫殿已搬上巨型移动平台。
- PDF 161：旧切尔诺伯格有三十余地块，高楼和工业设施密布，街面有源石动力载具和矿渣。
- PDF 163：重建后只余十余地块；传统建筑覆盖黑灰粉尘，城外有检查岗、铁丝网和源石探照灯。
- **设计约束**：帝国纪念性、重工业、巨型移动平台和寒地防线是可直接使用的城市层次。

## 拉特兰

- PDF 181：城外修道院除祈祷外还提供教育、医疗、食品生产并训练卫队，许多村镇围绕修道院形成；路灯也仿萨科塔光环。
- PDF 183：安魂教堂与街巷公共生活；城外村镇可在修道院受教育。
- PDF 184：每城区设区医院，周边村镇设诊所。
- **设计约束**：教堂/修道院可作为社区综合中心，公共服务设施密集；这些页面未证明全国统一白色外墙，材质仍须依官方背景取证。

## 伊比利亚

- PDF 191：港都曾把珍宝展柜放在街巷；大静谧后灯塔熄灭、宫殿沉海。
- PDF 195：伊比利亚之眼是守望泰拉的灯塔；码头喧嚣消失、耕地盐碱化。
- PDF 196：道路和建筑消失，庄园/粮仓废弃。
- PDF 199：南方港口城十不存一，海岸重绘，枢纽城成为废墟。
- PDF 200：曾建设水陆两栖移动城市，多数未完工即毁。
- PDF 201：幸存移动城与小聚落零散；灾后新聚落多以教堂或裁判所为中心。
- **设计约束**：港口、灯塔、水陆两栖移动城残迹与灾后教堂/裁判所聚落是不同层级，不能只做一个盐白灯塔。

## 阿戈尔

- PDF 207：诸城邦组成同盟，并对城邦进行科学规划。
- PDF 212：赫库兰尼姆因区位使用地热能源，多数阿戈尔城市使用氢能；物资经节点送到住宅/单位终端，并有光热控制。
- PDF 213：赫库兰尼姆用步足与推进器复合移动：步足撑起基座，底部有悬浮推进器，主/副推进器负责行进转向；约五分之一城市采用此方式。城市有居住层、能源井道和移动模块。
- **设计约束**：优先高技术模块城、能源/物流节点和复合移动基座，不得推成普通石砌海底古城。

## 谢拉格

- PDF 217—220：高山雪国；固定聚居点被险峰分隔并保持独立，散布在高原宜居区；中央盆地有融雪河、茂林和湖泊。
- PDF 222：建有少见的完整长距离山地铁路系统。
- PDF 223：聚落间交易粮谷、皮毛、矿石和工具，并有源石工业设施。
- PDF 224：蔓珠院向所有聚落派遣修士。
- **设计约束**：以分散高原聚落、铁路、宗教节点和工业设施形成网络，而非一个孤立雪山寺院。

## 卡西米尔

- PDF 227：平原上先修堡垒，再形成村庄。
- PDF 229—231：平原/丘陵为主、森林丰富；多数人口居移动城，固定点多为城周边中小村镇；乡村旧貌与繁华移动城反差强烈。
- PDF 234：移动城市支持跨地旅游赛事。
- **设计约束**：必须同时存在商业移动城与旧式乡村两层视觉，不能把全国竞技场化。

## 哥伦比亚

- PDF 237：移动采矿平台拖挂用废铁焊接的城镇；拓荒区由荒原、采矿平台和工业物流共同构成。
- PDF 239：大型移动城可改造为军事要塞并组成防线。
- PDF 240—241：东部大平原/砂岩峡谷，西部荒地，南端风蚀荒漠。
- PDF 242、246：州政府设于主要移动城；每州通常含数个主要移动城及周边城镇，约半数人口居移动城。
- PDF 250—251：大荒原、拓荒和企业新建工厂。
- **设计约束**：预制、矿拓、工业物流和军民两用移动平台有直接依据；科研室内不能代表全部城市外观。

## 玻利瓦尔

- PDF 259—260：北部发现资源丰沛的开阔平原后出现城镇。
- PDF 263：大部位于平原，中心有横贯平原的河流，北部为边境高原；九成人口生活在中央大平原。
- **设计约束**：本书未证明“多索雷斯灰泥/运河住宅”是全国建筑语法，须用具体背景和 PRTS 限定到多索雷斯。

## 叙拉古

- PDF 270：松散城邦组织；联合法院建筑曾是豪华家族宅邸。
- PDF 272：城邦盟会议事厅毁于爆炸，后形成城邦联合议事会/法院；家族宅邸向政务建筑转换。
- PDF 274：二十余城市均设市政府和法院。
- PDF 276：城市多雨，街道雨天仍热闹；西部为荒原；工业不发达，改造首都蒙特卢佩为移动城已很吃力。
- PDF 277—279：沃尔西尼新城区将分离为移动城市并安置居民；剧院是重要公共空间。
- **设计约束**：雨城街巷、家族宅邸转用、法院/剧院和新旧城区分离均有依据；“家族风格”不是统一材质。

## 萨尔贡

- PDF 280：开篇同时列出沙漠、雨林与古老城市。
- PDF 282：建立最初城市。
- PDF 283：南北山脉把国土分成东侧近海热带雨林与西侧远海山地/荒漠，主河形成三角洲和沿岸绿地。
- PDF 284：有高大宫殿。
- PDF 285、287：移动城市与固定定居点并存。
- **设计约束**：全国单一沙漠化与统一土坯风格均不成立；马纳特只能作为一个地区资产包。

## 米诺斯

- PDF 292：群山湖泊勾勒城邦；特色移动城和彩色建筑围绕高大英雄神殿，并有巨大露天剧场。
- PDF 293：城邦中心为英雄建殿堂。
- PDF 296：战时大量建筑和艺术品被毁，每城仅保留一座主要神殿。
- PDF 297：三座古城由萨尔贡改造为移动城，曾有巨大宫殿和花园。
- PDF 298—299：现有三座移动城，以神殿为核心议事厅，外辖城镇和村庄。
- PDF 300：巨像林立。
- **设计约束**：中心神殿—议事功能、剧场、彩色城市织体和巨像构成明确空间组织；不能只做现实古典小庙。

## 萨米

- PDF 302：森林和冻原。
- PDF 307：地貌由南向北为沼泽—森林—雪山—冻原四级变化。
- PDF 309：山脚要塞守卫冰原边界，但叙述者明确未亲见，要塞题材可信度降低。
- PDF 310：度假村房舍造型与木材刻字。
- PDF 312：族群可快速拔营迁移。
- **设计约束**：优先轻型、可迁移聚落和地形关系；统一祭仪石村无直接依据，要塞仅可作转述题材。

## 雷姆必拓

- PDF 315：卡特斯屯堡由洞穴和简易地表建筑构成；天灾时可收起/放弃地表并进入洞穴，后围绕屯堡形成聚落。
- PDF 316：早期聚落小而分散。
- PDF 317：最大移动城与矿井/工业语境。
- PDF 320：超过半数人口居住在各类移动采矿城市。
- PDF 321—322：矿业带动建筑、运输、加工、制造并承建大量移动城市与平台；出现“钢铁丛林”、移动城/采矿都市/矿井并列描述。
- **设计约束**：洞穴避灾、可放弃地表、采掘—运输—加工链和钢铁移动城都是结构层级。

## 炎

- PDF 324：全国十九宣政司；主要移动城为府，小型移动城/聚落分级；龙门是边关移动城；航道和驰道网改变景观。
- PDF 325：尚蜀地块散布山峦间，城际道路网络完善。
- PDF 328：制造/矿业基地、贸易口岸、索道和桥梁。
- PDF 330：龙门有卖场、工厂、港口和街巷经济。
- PDF 331：固定聚落房屋低层、街面近；移动城住宅高层，楼中层设步行街，屋顶设广场/商业“天街”。
- PDF 332：绕城公路、轮渡、自行车/公交专道、高架桥和潮汐车道。
- **设计约束**：炎必须按地区和城市等级拆包；移动城市是多层交通/商业系统，绝非单一古代院落。

## 东

- PDF 333—341：“极东来信”章节。
- PDF 336：寺院在广大农村乡野影响更强。
- PDF 338：源石工业时代后银行、工厂和分销集团发展，移动城取代旧形态。
- PDF 339—340：北方仿效炎进行基础建设和战后重建，扩建移动城、修航道；御机和锁川是最重要的两座移动城，并有源石精炼厂污染水源。御机城街景同时出现繁华灯光、装甲突击艇和武士队列。
- **设计约束**：工业移动城和基础设施是明确的现代层；町屋、神社不能被推成全国统一建材。

## 卡兹戴尔

- PDF 342：唯一移动城市沿唯一航道巡行；外壳为锈蚀钢铁，层叠居住区被金属窗栅包裹并堆在工厂脚下，伴有雷暴和“工业心脏”意象。
- PDF 343—345：古代银色山脉与城市属于传说/历史叙述，现址未确认。
- PDF 347—348：氏族堡垒由土石建成，由堡垒匠师多代加固；另有灰白城市和堡垒体系。
- PDF 352：城市毁灭后，第一座移动城成为工业心脏，并出现移动医院、移动农牧平台和流动学校。
- **设计约束**：锈钢工业移动城与土石氏族堡垒是两套层次；不能只做废墟或流动帐篷。
