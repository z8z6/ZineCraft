# 泰拉十九国与建筑资料总结

状态：`RESEARCH`  
更新：2026-08-16

本表以《大地巡旅》、本地官方游戏背景和 PRTS 地理索引为依据。它记录“资料展示了什么”，不把现实国家、现实建筑或文件名联想当作设定。视觉描述只适用于列出的画面与地点，不表示整个国家只有一种风格。

## 口径与页码

- 《大地巡旅》国家与地区章为书内 107—346 页；PDF 为扫描版，阅读器 PDF 页码通常比书内页码约多 8—9 页。
- 设定集覆盖维多利亚、莱塔尼亚、乌萨斯、高卢、拉特兰、伊比利亚、阿戈尔、谢拉格、卡西米尔、哥伦比亚、汐斯塔、玻利瓦尔、叙拉古、萨尔贡、米诺斯、萨米、雷姆必拓、炎、东、卡兹戴尔。
- 本轮“十九国”沿用项目现有现存国家清单：不含古国高卢和独立城邦汐斯塔，包含设定集国家章未单列的杜林。杜林只使用官方游戏背景与
  PRTS，设定集信息标 `U`。
- 文件路径均相对于 `F:\netdisk\明日方舟\CG、背景\背景`。

## 分国摘要

### 阿戈尔 Aegir

- **CANON/A/B**：《大地巡旅》198—207 页单列阿戈尔；PRTS：[阿戈尔](https://prts.wiki/w/泰拉大典:地理/阿戈尔)。
- **S / 城市与建筑**：`51_g4_aegirstreet_1.png`、`51_g5_aegirstreet_2.png` 展示深青黑街区、极高竖向体量、连续圆拱窗、桥廊和下沉层级；
  `51_g1_beaconsquare.png`、`51_g3_beaconctrlroom.png` 提供信标设施；`51_g9_shipport.png` 提供港口；`51_g11_aegirroom.png`
  提供室内。
- **Minecraft 保留项**：高宽比、层间桥廊、压力环境下的密闭表皮、冷青主体与铜金暖光比例。
- **未知/禁止扩写**：单张背景未展示完整城市基座、背立面和真实材料构造；不得把所有阿戈尔建筑做成神殿遗迹或海晶灯穹顶。

### 玻利瓦尔 Bolívar

- **CANON/A/B**：《大地巡旅》249—260 页；PRTS：[玻利瓦尔](https://prts.wiki/w/泰拉大典:地理/玻利瓦尔)
  。资料同时存在长期冲突与多索雷斯滨海城市，二者不能互相替代。
- **S / 多索雷斯**：`48_g1_dossolesstreet_n.png`、`48_g2_galleriessquare.png`
  及同组展馆/楼梯/海滩展示白色流线型大跨度展馆、晶体状地标、张弦/斜拉构件、宽阔浅色铺装、草坡和人工滨海空间。
- **Minecraft 保留项**：开放水平轮廓、展馆大跨、广场—水岸—地标三段关系。
- **未知/禁止扩写**：多索雷斯不能代表内战区域；旧原型的土坯、游艇和赛事检查站均须逐项补证据。

### 东 Higashi

- **CANON/A/B**：《大地巡旅》325—332 页；PRTS：[东](https://prts.wiki/w/泰拉大典:地理/东)。
- **S / 神田街区**：`64_g1_jindastreet_d.png`、`64_g2_jindastreet_n.png`、`64_g3_jindaalley.png`、`64_g18_kajistreet_n.png`
  展示窄深街廓、黑灰木/金属立面、密集外挂机械与招牌、跨街钢架，以及少量朱红大型构件；`64_g9_higashigarden_d.png` 和
  `64_g15_higashiroom.png` 提供园林/室内补充。
- **Minecraft 保留项**：深窄街道截面、檐口和现代管线的叠层、跨街构件，不靠单一红色或神社符号识别。
- **未知/禁止扩写**：现有“町屋、锻刀铺、茶屋、奉行所、神社”组合不能仅因现实联想成为国家套装。

### 杜林 Durin

- **CANON/B**：设定集国家章未单列，书内页码为 `U`；须以游戏文本和 PRTS 后续建立文字来源。
- **S / 理想城**：`30_g1_durinstreet.png`、`30_g4_durinsquare.png`、`30_g2_fountainlake.png`、`30_g10_lakegarden.png`
  展示地下人工花园、白色模块住宅、深挑檐/盒式阳台、垂直绿化、浅色小方格铺地和人工水景；`30_g5_library_indoor.png`、
  `30_g7_durinhall.png` 提供公共内装。
- **Minecraft 保留项**：地下顶界、明亮绿白体量、居住模块与花园/水景一体化。
- **未知/禁止扩写**：穹顶车站、游戏厅、水上乐园的国家普遍性未知；不得只做高饱和彩板游乐园。

### 哥伦比亚 Columbia

- **CANON/A/B**：《大地巡旅》228—248 页，含“荒地拾遗”；PRTS：[哥伦比亚](https://prts.wiki/w/泰拉大典:地理/哥伦比亚)。
- **S / 科研设施**：`38_g2_colombiaoffice.png`、`38_g1_rhinemeetingroom.png`、`38_g3_rhinelab_corridor.png`、
  `38_g5_rhinelab_indoor.png`、`38_g12_trimountrestarea.png` 展示低矮宽展空间、白/暖木/金属、整面线性照明、弧形模块家具、植栽与镜面；能源井组提供大型科研基础设施。
- **Minecraft 保留项**：水平延展、模块接缝、连续照明、科研交通与后勤空间。
- **未知/禁止扩写**：这些画面不能证明“拓荒镇治安官办公室”外观；监狱补给站、峡谷镇和铜绿调色板需独立来源。

### 卡西米尔 Kazimierz

- **CANON/A/B**：《大地巡旅》218—227 页；PRTS：[卡西米尔](https://prts.wiki/w/泰拉大典:地理/卡西米尔)。
- **S / 竞技场**：`bg_arena_1.png`、`bg_arena_2.png` 直接出现 KAZIMIERZ MAJOR，展示巨型封闭体育场、钢桁架顶棚、环形看台、悬挂中央屏和商业灯光。
- **Minecraft 保留项**：大跨顶棚、看台碗体、屏幕/广告作为空间系统而不是贴旗帜、场外集散广场。
- **未知/禁止扩写**：国家普通住宅和自然地貌不能由竞技场反推；骑士纪念碑、甲胄工坊和红金调色须逐项核对。

### 卡兹戴尔 Kazdel

- **CANON/A/B**：《大地巡旅》333—346 页；PRTS：[卡兹戴尔](https://prts.wiki/w/泰拉大典:地理/卡兹戴尔)。
- **S / 城市与设施**：`49_g2_kazdelstreet_d.png`、`49_g3_kazdelstreet_n.png`、`49_g5_furnaceplatform.png`、
  `49_g6_babeloffice.png`、`50_g6_sarkazancientruins.png` 展示拼装板房、波纹金属、外挂机组、尖锐防御构件、损伤街道、重型塔体和炉台。
- **Minecraft 保留项**：修补痕迹、外挂设备、狭窄街层与远景重塔的对比；暗红只作少量强调。
- **未知/禁止扩写**：不能把国家压成帐篷营地或黑石废墟；“巴别塔遗迹”外形须有具体画面才可还原。

### 拉特兰 Laterano

- **CANON/A/B**：《大地巡旅》166—181 页；PRTS：[拉特兰](https://prts.wiki/w/拉特兰) 明确启示石塔、围绕石塔建立城市及大教堂地下相关信息。
- **S / 圣城**：`26_g1_laterano_cathedralfront.png` 及 `26_g2`—`26_g12`
  同组大教堂、舞厅、礼拜堂、病房、住宅、街道、屋顶和办公室，展示象牙白大体量、金色细线、纪念柱、细长拱窗、重复拱廊、浅色广场与后方现代高塔。
- **Minecraft 保留项**：大教堂—广场—水面—高塔的轴线，白色主体和金色强调的面积比例，重复拱廊节奏。
- **未知/禁止扩写**：旧原型“修道院小镇”不等于拉特兰城；地下主机的完整外形和未展示区域必须标 C/U。

### 莱塔尼亚 Leithanien

- **CANON/A/B**：《大地巡旅》126—137 页；PRTS：[莱塔尼亚](https://prts.wiki/w/泰拉大典:地理/莱塔尼亚)
  记录移动城邦高塔、崔林特尔梅双塔、维谢海姆和夕照厅。
- **S / 城市与音乐厅**：`28_g1_gorgeousstreets.png` 展示浅石历史街墙、陡屋顶/尖塔和规整铺地；
  `28_g7_concerthall_outside.png` 展示红黑银、悬浮/外挑的巨大声学雕塑体；同组舞台和观众厅补充内部。
- **Minecraft 保留项**：传统城市底景与激进声学巨构的并置、垂直塔群和大跨度音乐空间。
- **未知/禁止扩写**：不能把全境简化为紫色魔法砖或现实中欧城市；十二塔的具体统一外形未知。

### 雷姆必拓 Rim Billiton

- **CANON/A/B**：《大地巡旅》306—314 页；PRTS：[雷姆必拓](https://prts.wiki/w/泰拉大典:地理/雷姆必拓)。
- **S / 矿业镇**：`46_g3_rmbttown.png`、`46_g6_rmbtmine.png`、`46_g2_rmbttransporter.png`
  展示高密度脚手架、栈桥、料斗/筒仓、管线电缆、波纹钢棚、货箱、巨大拱形开挖洞和连续肋架。
- **Minecraft 保留项**：采掘—处理—仓储—运输完整链条、纵横栈桥和洞体截面。
- **未知/禁止扩写**：一座小井架不能代表国家地标；矿工宿舍和食堂只能作为城市织体，不能替代工业轮廓。

### 米诺斯 Minos

- **CANON/A/B**：《大地巡旅》284—292 页；PRTS：[米诺斯](https://prts.wiki/w/泰拉大典:地理/米诺斯)。
- **S / 阿忒纽斯**：`69_g4_athenusstreet.png`、`69_g7_firsttemple.png`、`69_g8_templetheater.png`、`69_g10_templegarden.png`

- **Minecraft 保留项**：低宽石构前景与现代高塔背景的时代叠层、柱廊尺度和公共花园。
- **未知/禁止扩写**：必须再以正文确认 Athenus 的国家/地点关系；“橄榄市场、十二英雄神殿”不能由现实类比直接生成。

### 萨尔贡 Sargon

- **CANON/A/B**：《大地巡旅》272—283 页；PRTS：[萨尔贡](https://prts.wiki/w/泰拉大典:地理/萨尔贡)。国土与地区多样，马纳特不能代表全国。

- **未知/禁止扩写**：禁止把全国压成土坯绿洲和香料集市；东部雨林及其他地区需另立视觉资料。

### 萨米 Sami

- **CANON/A/B**：《大地巡旅》293—305 页；PRTS：[萨米](https://prts.wiki/w/泰拉大典:地理/萨米)。
- **S / 部族聚落**：`40_g5_samitribe.png` 与同组冻林、冰川、山洞展示架高木平台、陡斜大挑檐棚屋、开放火塘/工作区、木栈桥和不规则围合。
- **Minecraft 保留项**：建筑与冻林地形互锁、架高平台和栈桥网络、深木与暖火光的小比例对比。

### 维多利亚 Victoria

- **CANON/A/B**：《大地巡旅》110—125
  页；PRTS：[维多利亚](https://prts.wiki/w/泰拉大典:地理/维多利亚)、[伦蒂尼姆](https://prts.wiki/w/泰拉大典:地理/伦蒂尼姆)
  。伦蒂尼姆是移动城市，资料明确有外城防炮、兵工厂、下水道和中央区等地点。
- **S / 城市与地方**：`21_G3_victoria_street_d.png` 展示深红褐多层砖石、高窗、穹顶角塔、纪念柱/雕像广场和石栏杆；
  `45_g5_victoriabarracks_c.png` 为军营，`34_g1_victoriavillage.png` 为连排浅石农舍、烟囱、坡屋顶和湿润田地。
- **Minecraft 保留项**：伦蒂尼姆的工业移动都市层级、城市防御/兵工设施、深色高密街廓；地方乡村作为独立体系。
- **未知/禁止扩写**：不能把维多利亚等同现实英国或泛蒸汽朋克；蒸汽铁路站的具体外形不足，旧结构不进入深化。该国作为 Pilot，详见
  `countries/victoria/`。
