## 模数与兼容约束

- 新道路/中心使用32格街区单元、8格道路断面；建筑插槽位于边界中点。
- 单体临街宽度目标为17—31格，纵深24—46格，高度14—34格。
- 四个旧建筑文件名及四国公开 settlement ID 保留，新 builder 已进入正式生成。
- 每栋建筑必须显式声明实际占用单元，空隙率不得低于10%；入口、房间、楼梯、照明和箱体继续通过三维动线及遮挡光照验证。
- 国家 builder 不得调用共享房屋、屋顶、轮廓或房间 profile；共享代码只允许 NBT 编码、单方块/长方体放置与验证接口。
