## 实机核对门槛

1. 500/300格：国家天际线与主锚点必须先于材质读出。
2. 150格：模块间不应读成六个孤立盒体，桥、墙、道路和环境应形成组合。
3. 50格：门窗、肋架、退台、破损和机械后勤关系可辨。
4. 10格：门、楼梯、箱体、灯具承托和房间用途完整。
5. 证据为 `C/U` 的结构只能标记 Blockout；补齐地点级画面前不得声称 Canonical Reconstruction。
