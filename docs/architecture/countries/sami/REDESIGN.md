# 萨米建筑重设计

状态：`DESIGN CONTRACT IMPLEMENTED / IN-GAME REVIEW REQUIRED`
依据：《大地巡旅》PDF 302、307、309、310、312；官方背景 `40_g5_samitribe.png` 及同组冻林/冰川/山洞；PRTS 萨米地理索引；现有结构审计。

## 证据边界

- **S**：部族聚落为架高木平台、陡斜大挑檐棚屋、开放火塘/工作区、不规则围合与木栈桥；环境包含冻林、冰川和山洞。
- **A**：南北存在沼泽—森林—雪山—冻原梯度；族群可快速拔营迁移。山脚要塞仅为叙述者未亲见的转述，不足以高还原。
- **B**：PRTS 用于国家、地点和组织名称索引，不把整理页的现实文化类比作为造型依据。
- **C**：可将结构拆成可撤收的台架、棚体、储物与路径模块；“可撤收”是 Minecraft 功能转译，不声称官方机械构造。
- **U**：统一部族平面、原创图腾、独眼巨人祭坛完整形制、雪祀仪式流程和全国统一石材均未知。

## 不可混用的语境

1. **南部冻林迁移营地**：轻型、低密、架高、栈桥随树木与湿地转折，暖火只集中在生活节点。
2. **雪山/冻原边缘观测网络**：封闭、抗风、节点稀疏，以山洞、避风墙和远距信号连接；不得把未经目击的“山脚要塞”做成国家标准城堡。

两者不得共用一套“祭仪石村”。前者以木平台和可迁移性识别，后者以地形嵌入、遮蔽和观测线识别。

## 总体语法

- **形体/尺度**：聚落不追求孤立 XXL；S/M 棚屋由 5—9 格宽台架组团，整体网络可达 L。轮廓为低矮棚体、长挑檐、断续平台。
- **密度**：建筑低密，路径密度高；保留树、岩、雪沟，而非清平场地。
- **材料**：`sami_frost_moss` 只作自然基础，深色原木/木板作主体，`sami_ritual_stone` 仅限有明确仪式/边界用途的少量节点；雪层、皮革感遮棚和粗绳索作辅材。
- **光照**：火塘和室内暖光为主，路径使用有立柱承托的低位灯；冻原观测点使用克制冷光。不得悬空灯或满地发光冰。
- **基础设施**：架高栈桥、可拆卸坡道、雪橇/物资台、避风墙、洞口仓储、融雪集水和信号柱。
