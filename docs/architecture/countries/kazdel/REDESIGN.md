## 不可混用的语境

### K1 锈钢工业移动城

- 形体：工厂基座上叠加不齐的居住盒、外露楼梯和管线，塔体与街巷形成强烈高差。
- 尺度/密度：街屋 S/M，工业节点 L；高密、窄街、跨层栈桥。
- 材料：`kazdel_fortress_plate` 为主体，`kazdel_scarred_ash` 只作地面；深灰、焦褐，暗红为小面积识别色。
- 光照：金属梁承托的工作灯、炉火与维护灯；不把灵魂灯作为全国照明语法。
- 基础设施：工厂、锅炉/动力、升降、货运、移动医院与学校模块；Create 机械必须串成生产或物流链。

### K2 土石氏族堡垒与固定聚落

- 形体：贴地厚墙、逐代加固的异质墙段、内院与防御折角；不套用移动城的金属塔群。
- 尺度/密度：单堡 M/L，外围住宅 S；低密组团并服从地形。
- 材料：土石和修补木构为主体，装甲板只用于后加固门、射口或机械节点。
- 光照：墙龛、灯柱、火塘，均有实体承托。
- 基础设施：蓄水、储粮、医护、牲畜/农牧和避难空间；不存在证据时不铺设大规模工厂。

## 禁止与 UNKNOWN

- 禁止把卡兹戴尔等同“黑石废墟、恶魔城堡、帐篷营地”，禁止用尖刺和暗红铺满所有表面。
- 禁止把战损做成随机噪声；损伤必须对应冲击面、修补板、失效管线和可通行动线。
- `UNKNOWN`：移动城完整底盘、巴别塔全貌、堡垒氏族差异、官方徽标；旗帜只能是无文字原创体素标识并记录为 ORIGINAL。
- 所有箱子须在完成地板上一格，逐室独立战利品表；任何设定物品必须先确认已注册 ID 和来源。
