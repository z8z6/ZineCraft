## Pilot 选择

首个资产选择“伦蒂尼姆外城防炮/高墙段”，理由：

1. 名称、地点和防御核心用途可确认；
2. 旧仓库已有稳定 ID，能形成明确替换目标；
3. `27_g4` 提供可见的长炮管、斜面装甲炮座、连续高墙与城市背景；
4. 适合验证 32 格模块、L 级尺度和城市环境一起设计。

由于画面国别归属目前是 C 级，第一版只能标 `Silhouette Study`，不能标 `Canonical Reconstruction` 或 `FINAL`。
