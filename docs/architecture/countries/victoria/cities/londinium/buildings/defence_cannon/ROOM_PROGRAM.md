## 连通性

四个墙体模块均设下层与上层中央走廊。十二个墙内房间各有一组两格宽黄铜门直接通往对应楼层走廊；主楼梯在 `y=8`
设置侧向平台接入上层，并继续通往 `y=17` 城墙顶。屋顶出口前移一格，最后一级楼梯上方连续两格保持空气，避免玩家卡头。

炮塔入口不再依赖不可通行的 Jigsaw 接头：`wall_front_left` 的城墙顶设置连续检修梯，向上穿过空气化接口，进入 `turret_core`
的安山机壳入口隧道，再经黄铜门抵达后膛舱。生成验证会分别对两层走廊、十二组房门、四座楼梯和后膛入口做洪水连通检查。

## 墙地面与照明

- 墙体房间：Create `andesite_casing` 地板、墙和顶棚；中央走廊保留维多利亚防滑钢地板。
- 房间顶棚按四格网距嵌入海晶灯。对每个可使用地面格计算至最近光源的三维曼哈顿距离，必须不超过 14，确保理论方块光亮度大于 0。
- 后膛舱在 `y=12` 设置连续 Create 金属梁与嵌入式高输出灯；所有高输出灯必须邻接机壳、楼板、骨架或金属梁，生成器会拒绝悬空灯。
- 每个房间设置有实体墙背板的原创维多利亚纹章挂旗；屋顶旗帜固定在结构框架上。红底、黑边与金色抽象盾冠层纹只转译官方图标的纹章气质，不复刻其轮廓。
- 该检查保证无完整黑格，但实际视觉亮度仍受客户端光照、光影包和家具遮挡影响，需实机复核。
