## Architecture Pass 02

2026-08-16 已加入五种原创维多利亚城防材质，完全替换炮体混凝土占位；内部由显式空气体积形成可通行空间，并划分为火控室、源石军械储存区、维修间、乘员补给间和后膛检修舱。Create
6.0.10 的传动轴、大小齿轮、金属梁、工业铁块、流体管道和机械泵用于机械细节。

四类宝箱分别绑定 `control`、`ordnance`、`maintenance`、`supply`
战利品表。补给箱含维多利亚中央谷地烤肉；其余按房间投放源石工业材料、机械零件和低概率军械藏品。由于项目尚无正式源石炸弹物品，不在容器中伪造同名物品。

## Architecture Pass 03

四段城墙已通过成对边界门洞组成连续内部环路，每段都有一条从生活层到 17
格高屋顶步道的实体楼梯；炮塔后膛另有独立楼梯通往上层炮位。主走廊、功能房、屋顶步道、炮塔和两段炮管均补充灯笼或吊灯。

设施新增火控座椅和仪表、会议桌椅、书架、三张床、维修工作台、窗户、盆栽、弹药架及补给区。Create
机械扩展为齿轮箱、离合器、飞轮、转速表、应力表和模拟拉杆。外形加入阶梯扶壁、削切上角、残缺胸墙、墙面破口和屋顶弹坑，并以两种原创战损装甲控制弹孔/爆蚀分布。

## Architecture Pass 04

室内完成面已统一降至 `y=1`，容器和家具位于 `y=2`，修复房间地板覆盖宝箱的问题。四段城墙的楼梯改为最后施工：楼梯会切开屋面并接到
`y=17` 的安山机壳平台，出口两侧设置铁栏杆和高亮工作灯，避免后续屋面、胸墙或战损步骤重新封死通路。

城墙顶部服务道增加连续护栏、金属梁灯柱、海晶灯、补给箱、桶、铁砧、砂轮和射击靶；灯笼保留为气氛与路径标识，海晶灯与点亮红石灯承担主要工作照明。内部墙面和房间地面改用
Create 安山机壳，五个主要功能房均配置 Create 黄铜双开门，并加入灰/红地毯、发光房间牌和“保持警戒 / KEEP WATCH”中性玩法标语。

作战会议室扩建为九格长会议桌，四周设十个座位，配置书架、盆栽和体素化“泰拉地形球”。该球只承担战术空间陈设，不宣称复原官方世界地图。因结构
NBT 不适合在本轮稳定放置绘画实体，墙面叙事先使用有支撑的告示牌完成，避免引入会在结构加载后脱落的装饰实体。

## Architecture Pass 05

室内改为由 `ROOM_SPECS` 驱动的九房间程序，不再依靠散落坐标暗示用途。八个墙内房间均具有明确的 `14×13` 外框、`12×11`
净面积、完整安山机壳地面/四壁/顶棚、独立黄铜双开门和用途匹配的家具与战利品；第九个房间为炮塔后膛检修舱。完整划分见
`ROOM_PROGRAM.md`。

所有墙内门直接接入中央走廊，走廊连接模块边界与四条屋顶楼梯。炮塔向下 Jigsaw
接口改为空气通口，新增与城墙顶对齐的检修梯、安山机壳入口隧道和后膛黄铜门，修复炮塔内部原本无法由墙顶进入的问题。

照明不再以“每模块灯具总数”代替覆盖：每个房间按四格网距布置海晶灯，并在生成时逐一验证每个室内地面格至最近主光源的距离不超过
14。战利品新增 `planning` 类型，使用项目已从 PRTS/游戏数据导入的地区行动方案、全局作战文件、路线说明图、黄铜指南针等低概率藏品；唯一角色叙事物品保持排除。

## Architecture Pass 06

四段墙体由单层八室扩展为上下两层十二室，加上炮塔后膛舱共十三个功能房间。新增城防指挥厅、工程控制厅、测距观测厅与预备炮组室；每层拥有独立中央走廊和黄铜双开门，主楼梯在上层设置侧向平台后继续通向城墙顶。屋顶落脚平台前移并清空末级上方两格，修复玩家上楼时卡头。

每个房间新增带实体背板的维多利亚纹章挂旗，屋顶旗帜固定于结构框架。图案使用红底、黑边、金色抽象盾冠的原版旗帜层组合，只转译官方图标的纹章气质，不复制其具体轮廓。挂旗同时承担稳定的墙面装饰，避免绘画实体随结构加载脱落。

下层与上层主照明均嵌入安山机壳顶棚；后膛灯带嵌入连续 Create 金属梁。生成器新增灯具承托检查与旗帜背板检查，任何悬空高亮灯或无支撑墙旗都会中止生成。

## 问题

1. 炮管当前完全水平，官方画面存在轻微透视/仰角差异；需要游戏内相机对照后决定是否做 1:8 或 1:16 抬升。
2. 炮座五级退台是体素近似，不足以证明官方装甲分板。
3. 内部已进入 Architecture Pass，但仍需在游戏内确认跨 Jigsaw 接缝的动线是否连贯。
4. 缺少第二炮座、后方城市体块和墙外空间，Environment 项暂为 0。
5. 画面国别归属仍是 C 级；在找到该背景对应剧情/关卡索引前不能升级为 Canonical Reconstruction。
