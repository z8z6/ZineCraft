国家辨识不能只依赖砖红色。伦蒂尼姆应由“超大地块尺度 + 城墙/防御 + 工业支持层 + 高密街层”共同识别。

## Architecture Language

- **移动城**：生活层承载道路、桥、广场和街区；支持层表达锅炉、供电、水循环、升降电梯与港口运输；动力层表达履带、动力炉和储运。
- **伦蒂尼姆城墙**：高墙顶是连续防御平台，炮座用宽大的斜面装甲体承托长炮管；后方不是空地，而是高密工业/城市体量。
- **城市街区**：3—5 层连续街墙，高窗形成稳定竖向节奏；角部使用体量抬高而非孤立塔尖；公共广场留出视线和交通轴。
- **地方乡村**：1—2 层、连排浅石墙、坡屋顶与烟囱，矮墙和未硬化道路连接田地；不得直接拿来填伦蒂尼姆核心区。
- **军事临时设施**：轻型木/金属框架和帆布覆盖，内装强调工作台、照明和后勤，不代表永久城防建筑。

## City Layers

```text
Primary Landmark     城墙与城防炮 / 指挥塔级体量
Secondary Landmark   兵工厂、运输港、工业坞、车站
High-rise Cluster    核心地块高密城市背景
Mid-rise Layer       连续砖石街区和公共建筑
Street Layer         广场、道路、桥、店面、栏杆、升降口
Support Layer        锅炉、电力、水循环、港口、电梯与管线
Power Layer          动力炉、储运、履带和维护通道
```

## Facade Rhythm

- 城市街层：宽墙段由窄高窗重复切分，底层店面/公共入口更开敞。
- 防御设施：装甲面采用大块斜面，水平检修线与竖向支撑交叉；不要用城堡垛口代替工业墙体。
- 工业层：大尺度设备间距优先于微小管线；先呈现吊装、运输、动力和维护路线。

|-----------|-----------|---------------|----------|
| Primary   | 深红褐/烟灰砖石  | 冷灰、灰黑装甲       | 浅暖石灰/灰褐石 |

## Lighting

- 伦蒂尼姆街道以雾天漫射光和深阴影形成尺度；不要全城高饱和霓虹。
- 工业/城墙内部用连续冷白工作灯标出维护路线。
- 暖光只用于窗、工作区或设备状态，控制面积。

## 禁止项

- Big Ben、Westminster、Buckingham Palace 等现实建筑复制；
- 用红砖 + 齿轮 + 铜管自动等同维多利亚；
- 把乡村连排住宅直接缩放成首都地标；
- 在城墙上使用中世纪垛口代替官方画面的斜面工业炮座；
- 在看不见的背立面上添加无来源徽标、王冠或纹章。
