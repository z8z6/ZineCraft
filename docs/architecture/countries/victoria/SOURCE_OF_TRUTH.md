# Victoria Source of Truth

状态：`ACTIVE / PILOT`  
更新：2026-08-16

## 官方到底展示了什么？

维多利亚拥有规模极大的移动城市与领先机械工程；伦蒂尼姆是由多块超大地块组成、具有产业分区和城墙的首都。官方背景同时展示高密砖石城市街区、军事/工业设施和与其明显不同的地方乡村。伦蒂尼姆城防炮位于包围首都的高墙上，是城市防御核心。

## 哪些内容未知？

- 城防炮完整俯视、背面、内部传动和精确比例；
- `27_g4_giantwall.png` 的文件名没有直接写“伦蒂尼姆”，其归属依赖同组碎片大厦、轻工业区等剧情语境，因此画面用于 C 级保守视觉参照；
- 普通城市砖石画面是否代表伦蒂尼姆全部城区；
- “蒸汽铁路站”现有旧结构的官方对应场景；
- 移动城市每块地块的完整连接和底盘细节。

## Minecraft 最应保留什么？

1. 单块地块已超过中小移动城的尺度感；
2. 生活层—支持层—动力层的垂直结构；
3. 城墙、防炮、兵工/工业区与交通系统的城市级关系；
4. 高密街区的大开窗、连续立面节奏和公共广场；
5. 城市与低矮、湿润地方乡村的视觉反差。

## 来源冲突与排除

- `SOURCE_CONFLICT`：PRTS 页面底部的现实词源/现实建筑原型考据不进入 Canonical Reference。
- 红砖、坡屋顶和蒸汽不能脱离具体官方画面推成“英国/蒸汽朋克”国家套装。
- `bg_victoria.png` 虽文件名明确，但地点和时代语境未在本轮确认，不用于首个 Blockout。
- 旧 `victoria_steam_station` 没有足够官方视觉覆盖，保持 `PROTOTYPE_NON_CANONICAL`。
