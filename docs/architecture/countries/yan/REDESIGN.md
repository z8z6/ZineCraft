# 炎建筑重设计

状态：`DESIGN CONTRACT IMPLEMENTED / IN-GAME REVIEW REQUIRED`
依据：《大地巡旅》PDF 52、324—332；官方背景 `25_g05_mountaincity_d.png` 及尚蜀组、`35_g1_yumenstreet_d.png`、
`35_g3_yumenobservationtower.png`、`35_g6_yumengate.png`；PRTS 炎；现有结构审计。

## 证据边界

- **S**：尚蜀为山城/山路/亭与街区组；玉门具有巨型纵向肋板金属城防体、工业道路、青灰/沙褐分区；另有龙门现代城市画面。
- **A**：炎有多级移动城/固定聚落；尚蜀地块堆叠山丘并设索道；制造、矿业、贸易口岸、桥梁与道路网发达；移动城住宅高层、中层步行街、屋顶商业天街，另有复杂城市交通。
- **B**：PRTS 用于炎、尚蜀、玉门、龙门的城市与地点索引。
- **C**：山地排水、索道换乘、玉门门体维修层和移动城垂直物流可依官方系统保守补全。
- **U**：全国统一建筑风格、玉门城门内部、尚蜀单体背立面、旧“院落/茶馆/亭”四件套的普遍性。

## 不可混用的语境

1. **尚蜀山地移动城**：人工山丘、错台街层、桥/索道、低中层街廓和竖向景观共同构图。
2. **玉门边防移动巨构**：大尺度金属肋板、城门、观测塔、工业道路与防御/物流轴。

龙门应另立第三城市包：高层住区、中层步行街、屋顶天街、港口与高架交通；不得把三地混为“古风炎城”。

## 总体语法

- **形体/尺度**：尚蜀由 S/M 街屋和 L 地形组团构成；玉门城门 XL；龙门街区 L。先做山体/城门/交通轮廓，再做檐口细节。
- **密度**：尚蜀沿坡中密、多层路径；玉门低建筑密度但设施尺度巨大；龙门高密垂直混合。
- **材料**：`yan_mountain_soil` 作山体表层，`yan_courtyard_brick` 仅用于有画面支持的院墙/街层；玉门用青灰/沙褐金属、结构骨架与防滑路面。
- **光照**：尚蜀路径和檐下暖光；玉门连续工作灯与警示灯必须附着肋板/灯杆；龙门商业照明按具体画面控制。
- **基础设施**：索道、桥梁、驰道、货运升降、港口、高架道路、公交/轮渡接口、排水与移动城支持层。

## 禁止与 UNKNOWN

- 禁止把炎等同现实中国、复制故宫/长城，或做“单一朝代古建合集”。
- 禁止仅靠红柱、灯笼、青砖和飞檐识别；玉门不得套传统院落外皮。
- **UNKNOWN**：各宣政司统一规格、玉门内部、尚蜀索道机械细节、旗帜和文字；原创标志必须无官方冒充。

## 实施门槛

首个资产为玉门城门轴线 XL Blockout，至少拆地基、左右门体、桥、塔、道路和支持层；尚蜀另开地形组团，绝不共用玉门调色板与模块。
