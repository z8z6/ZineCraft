## 不可混用的语境

### L1 拉特兰城大教堂—广场—现代高塔轴线

- 形体：纪念性大体量与重复拱廊作前景，开阔广场/水面留出视距，后方为更细长的现代塔群。
- 尺度/密度：地标 XL/XXL，街块 M/L；核心轴线疏朗，侧街中高密。
- 材料：`laterano_basilica_marble` 为白色主体，金色仅作边线和节点；地下设施才使用 `laterano_host_casing/conduit`。
- 光照：连续壁灯、柱灯和有灯杆承托的“光环式”路灯；室内主照明嵌入拱肋/顶棚。
- 基础设施：公共医院、办公、街道与地下服务层；不得以礼拜空间替代所有城市功能。

### L2 城外修道院服务聚落

- 形体：围院式综合体与周边村镇，农产/诊所/课堂/训练场清晰分区。
- 尺度/密度：修道院 L，村镇 S/M；中心紧凑、外围农产用地疏松。
- 材料：地方石材与灰泥为主体；白金大理石仅用于重要公共面，不能复制首都轴线。
- 基础设施：食品生产、医疗、教育、卫队和蓄水；这是功能证据，不等于所有修道院外观相同。

## 禁止与 UNKNOWN

- 禁止“拉特兰=现实宗教国家”，禁止照搬现实教堂、徽记、文字或十字符号。
- 禁止白色与金块满铺；金色只用于轮廓边线、门窗节点与导向。
- 禁止把修道院小镇当拉特兰城，或把礼拜堂当作医院、学校和行政的外观替代。
- `UNKNOWN`：启示石塔完整几何、地下主机实际构造、安布罗修礼拜堂外形。地下主机只能维持现有原创玩法声明，不称官方复刻。

## 进入 Blockout 的门槛

优先以 L1 的大教堂前广场轴线做 XL 多模块 Blockout；城外修道院另建 L2 资料包。两者不得共用同一聚落池。
