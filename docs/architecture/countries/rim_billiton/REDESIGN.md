## 不可混用的语境

### R1 洞穴避灾屯堡

- 形体：洞口/岩壁是主体，地表为轻型可拆棚、折叠栈桥和少量瞭望；地下生活与储备空间完整。
- 尺度/密度：地表 S、地下 M/L；地表疏散，洞内沿主巷紧凑。
- 材料：天然岩体、木/轻钢支撑，`rim_billiton_corrugated_steel` 用于可替换地表壳。
- 光照：洞壁支架灯、顶梁灯和应急导向灯，不允许悬空。
- 基础设施：封闭门、通风、排水、储粮、医护与撤收仓；不引入完整冶炼厂。

### R2 移动采矿城市与工业链

- 形体：巨大开挖洞、连续肋架、料斗/筒仓、运输栈桥和管线决定轮廓，宿舍只是附属。
- 尺度/密度：核心工业 L/XL，工人建筑 M；垂直高密“钢铁丛林”。
- 材料：`rim_billiton_corrugated_steel`、结构钢、矿渣地面，锈橙仅出现在磨损和警示节点。
- 基础设施：采掘、处理、堆存、装车、供电、除尘、排水和维护闭环。

## 禁止与 UNKNOWN

- 禁止把雷姆必拓缩成一座小井架，或用宿舍/食堂替代采掘—运输—加工轮廓。
- 禁止无来源企业徽标、现实矿企制服、任意黄黑警示文字；原创无文字几何标识须标 ORIGINAL。
- `UNKNOWN`：具体矿车、轨距、企业标识、采矿城底盘；Create 只是 Minecraft 机械转译，不代表官方设备。
