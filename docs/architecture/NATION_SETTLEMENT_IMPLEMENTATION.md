# 十九国聚落结构实现

状态：`ARCHITECTURE PASS / IN-GAME REVIEW REQUIRED`
更新：2026-08-16

本轮依据十九份 `docs/architecture/countries/<country>/REDESIGN.md`，替换
`nation_settlements` 下的旧统一盒体结构。正式聚落路径、四个兼容建筑 ID、
`center` 和四种 `street_*` 文件名全部保留，因此现有 Jigsaw 池与世界生成注册无需迁移。

## 实现范围

- 19 个中心、76 个街道模块、76 栋功能建筑，共 171 个 NBT。
- 76 栋建筑分别声明 `size / silhouette / roof / role / feature`，生成器拒绝重复设计元组。
- 建筑临街宽度为 7—9 格，避免相邻的 9 格街道插槽互相碰撞；纵深为 18—24 格，保证至少一个水平轴达到 S 级 16 格门槛。
- 各国继续使用已注册国家地貌和外墙材料；原版/Create 仅承担屋面、门窗、灯、家具、结构梁、管线和可读机械链。
- 被设计合同改名或冻结的旧 ID 只作为兼容路径。例如 `arcade` 实现为杜林公共图书活动厅，`sheriff_office` 实现为哥伦比亚平台行政应急中心，
  `ritual_house` 实现为萨米部族集会棚。

## 可玩性约束

每栋建筑均包含可开启的成对门块、显式内部空气、贯通入口的主通道、用途家具、带国家战利品表的容器，以及附着在屋面或结构梁下的主照明。二层建筑使用五级实体楼梯，楼梯井穿透上层地板，逐级保留两格头部净空。

容器统一引用：

```text
zinecraft:chests/nation/<country>_structure
```

箱体位于完成地板上一格；功能内饰按住宅、实验、物流、档案、市场、工坊、演出、公共服务、旅宿、餐饮、诊疗、交通、训练、供水和集会分类。

## 国家轮廓语言

生成器没有复制官方徽标或文字，国家差异来自设计稿允许的形体与基础设施：阿戈尔耐压肋与封闭桥、玻利瓦尔大跨遮棚、哥伦比亚服务脊、杜林花园阳台、东跨街设备架、卡西米尔场馆桁架、卡兹戴尔修补框架、拉特兰克制拱廊、莱塔尼亚声学翼片、雷姆必拓矿业门架、米诺斯公共柱廊、萨尔贡遮阳与供水、萨米高脚栈桥、维多利亚工业烟道、乌萨斯供暖干管、谢拉格挡雪台、叙拉古雨廊排水、炎山地错台和伊比利亚盐蚀扶壁。

## 自动验证

`script/generate_nation_settlements.py` 在写 NBT 前检查：

- 19 个路径、76 个显式设计和 171 个兼容文件完整且无重名；
- 临街宽度不超过 9 格，至少一个水平轴不少于 16 格；
- 内部空气量、双门，以及脚/头可通过且脚下有实体支撑的完整三维站立图；
- 从入口开始验证全部声明楼层、每级楼梯站位、顶部落脚和主要房间目标属于同一连通分量；
- 灯具数量和六向实体承托，并以最多 15 级、受不透明墙体阻挡的六向方块光泛洪验证所有房间站立格；
- 容器地板高度、方块实体 NBT 与国家 LootTable；
- 二层实体楼梯数量及每级两格净空；
- Jigsaw 的 `name/target/pool/final_state` 与国家道路接口；
- 不残留混凝土占位，且每栋至少使用十种结构/内饰材料。
