## 评分方法

`ReferenceRichness` 只衡量当前可用资料，不衡量国家重要性或个人喜好：

- 设定集国家章与明确文字：25 分；
- 有地点锚点的官方建筑背景：35 分；
- 已命名城市/建筑/基础设施覆盖：25 分；
- 同时覆盖远景、街道、室内或基础设施中的多层尺度：15 分。

设定集未单列的杜林不会补猜分数。`Priority` 综合 ReferenceRichness、Visual Uniqueness、City Scale 和 Available
Architecture；分数接近时优先能形成完整“地标—街区—道路—基础设施”试点的国家。

## 阶段路线

### Phase 0.5 — 十九国重设计合同（已完成）

- 为十九国分别建立 `docs/architecture/countries/<country>/REDESIGN.md`。
- 共覆盖现有 76 栋聚落功能建筑与 38 座地标；每项明确保留、改名、替换或冻结。
- 每国至少拆分两套不可混用的城市/聚落语境，并定义尺度、轮廓、模块、房间、Create 机械链和战利品类别。
- 该阶段本身只完成设计合同，不代表逐国 `SOURCE_OF_TRUTH`、`VISUAL_BIBLE` 或 Fidelity Review 已通过。
- 总索引与共用约束见 `docs/architecture/ALL_NATIONS_REDESIGN.md`。

### Phase 0.6 — 兼容结构替换（已完成，待实机评审）

- 保留 19 套聚落、76 个功能建筑和 38 个地标的公开 ID。
- 聚落替换为 171 个有室内、动线、照明、家具、机械和国家战利品的 NBT。
- 地标替换为 38×6=228 个 `foundation/core/facade/roof/annex/surrounding` 模块，并改用确定性 Jigsaw 池。
- 资源状态为 `ARCHITECTURE_PASS / IN-GAME REVIEW REQUIRED`；实机评审前不得升级为 `FINAL`。

### Phase 0 — 全局基线（本轮）

- 完成 19 国资料总表、旧结构审计、Pipeline 和 Roadmap。
- 冻结 209 个旧结构 NBT 为 `PROTOTYPE_NON_CANONICAL`，保留 ID。
- Pilot 选择维多利亚；只为 Pilot 建立五份基础文档。

### Phase 1 — Victoria Pilot

1. 伦蒂尼姆城市视觉规则与来源板；
2. 选择一项 Reference Coverage A/B 的大型资产；
3. 制作 64+ 格模块化 Blockout；
4. 在 500/300/150/50/10 格距离进行轮廓评审；
5. 通过后再制作立面、材质、环境和替换注册。

当前优先候选是“伦蒂尼姆外城防御设施/城防炮”，因为 PRTS 有明确地点与用途，设定集有维多利亚工业/移动城市文字，且旧仓库已有兼容
ID `victoria_defence_cannon`。但在取得足以支撑完整炮体比例的官方画面前，只做 `Silhouette Study / BLOCKOUT`，不宣称高还原复刻。

### Phase 2 — 高资料国家

- 炎：分别建立玉门边防、尚蜀山城和龙门城市包；首个 Blockout 优先画面充分的玉门城门轴线。
- 拉特兰：大教堂前广场与城市轴线，后续再处理地下主机。
- 阿戈尔：信标广场—控制室—港口的竖向海工组团。
- 卡西米尔：大骑士竞技场的看台碗体、顶棚桁架和集散广场。

### Phase 3 — 工业与地形验证

- 雷姆必拓矿业链；
- 谢拉格山城交通；
- 伊比利亚坡地盐风镇；
- 卡兹戴尔拼装战损城市；
- 乌萨斯北方城市与军工设施。

### Phase 4 — 需补局部证据

- 莱塔尼亚、叙拉古、萨尔贡、哥伦比亚、米诺斯、玻利瓦尔、东。
- 先补城市/地点级 `SOURCE_INDEX`，再决定地标，不复用旧名称作为需求。

### Phase 5 — 低大型建筑覆盖

- 萨米：优先做地形—聚落—栈桥网络，不强造 XXL 建筑。
- 杜林：补游戏文本/PRTS来源后再确认理想城公共设施；不得用游乐设施替代整个文明。

## Pilot 完成定义

维多利亚 Pilot 只有在以下条件全部满足时才可结束：

- 五份国家文档完整且逐条链接来源；
- 第一栋大型建筑 Reference Coverage ≥ B，或明确标为 D 级 Silhouette Reconstruction；
- Blockout 至少 L 级且模块化；
- Canonical Review 记录所有锚点、未知面和 OriginalContentRatio；
- 不覆盖旧注册结构，直到 Blockout 评审通过；
- Architecture/Material Pass 后 `test`、`runData`、`build` 通过，并完成游戏内 `/place structure` 验证。
