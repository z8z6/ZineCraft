# Zinecraft 萌新内容修改手册

这组文档面向第一次接触 Minecraft 模组项目的开发者。每篇只讲一种内容怎样修改，不要求先理解 NeoForge、注册表或数据生成器的工作原理。

## 建议阅读顺序

1. [开始之前](GETTING_STARTED.md)：准备环境、备份改动、运行项目。
2. [修改方块](BLOCKS.md)：新增普通方块、改名称、硬度、掉落和贴图入口。
3. [修改材质](MATERIALS.md)：普通方块贴图、十九国地貌材质和官方 CG 裁片。
4. [修改群系](BIOMES.md)：天气、颜色、植被、生物、地面方块和分布位置。
5. [修改结构](STRUCTURES.md)：替换 NBT、使用结构方块、聚落和地标生成脚本。
6. [修改维度](DIMENSIONS.md)：泰拉中心范围、维度环境、群系列表和传送验证。
7. [修改藏品](COLLECTIBLES.md)：修改文字、稀有度、效果、图片与批量导入。

## 先记住三条规则

- 不要手工编辑 `src/generated/resources/`。这里的文件会被 `runData` 重新生成。
- 修改群系、维度或自然生成结构后，要在新世界或未生成区块测试。旧区块不会自动变化。
- 明日方舟名称、描述和图片只使用官网、游戏数据或 PRTS 中能够核对的内容；不要凭空补写设定。
